# CV / Resumes Directory

Place your official PDF resume files in this directory. The portfolio automatically links to the following filenames:

- `Demian_Avolstiyniy_Project_Manager_CV_RU.pdf` — Downloaded from `/project` (when RU language is active)
- `Demian_Avolstiyniy_Project_Manager_CV_EN.pdf` — Downloaded from `/project` (when EN language is active)
- `Demian_Avolstiyniy_Product_Manager_CV_RU.pdf` — Downloaded from `/product`
- `Demian_Avolstiyniy_Business_Assistant_CV_RU.pdf` — Downloaded from `/business`

To update a CV, simply replace the corresponding file in this `public/cv/` directory.
If you need to change file paths or URLs, edit `CV_LINKS` in `src/data/portfolioData.ts`.
